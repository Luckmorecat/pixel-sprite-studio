# Validation of 4.2

Validated on Linux with Python 3.12.14, ImageMagick 7.1.1-43, Pillow 12.3.0, Node.js 24.19.0 and skills CLI 1.7.0. Validation used disposable project-scoped installations and did not modify global/personal catalogs.

## Deterministic checks

- Five independent core packages each pass 190 tests; the independent exporter passes 42: 992 executions, 232 unique helper tests. No failures or skips
- The 32 standalone-record tests cover pending/failed/cancelled calls, repair caps, immutable evidence and path reuse, exact approval/delegation hashes, separate technical/visual gates, actual native PNG contracts, CLI operation and evidence-only bundle relocation/resume with nonzero counters
- One additional packaging test checks complete generated parity and deliberately detects script, reference and template drift
- The inherited `artifact_bundle.py` and `test_artifact_bundle.py` intentionally changed in each core package for compact-checkpoint consistency and static handoff coverage. No baseline helper was removed; the exporter encoder remains unchanged
- All six skill frontmatters pass the skill-creator validator. JSON templates parse. Entry-point resource links resolve, and generated packages contain no symlink or private-environment dependencies
- Canonical-source build parity covers all 225 distribution files; shared scripts, references and templates additionally match across five core packages. Package-specific icons and the action-style example are explicit overlays

## Install checks

The skills CLI discovers exactly six skills. Final-policy project-scoped `--copy` installations in disposable sandboxes cover all six together and each skill alone: seven installation selections. Every installed file matches its generated distribution byte-for-byte. Each individually installed core package passes 190 tests and the exporter passes 42, another 992 helper executions with no failures or skips. This verifies standalone package completeness without modifying global/personal catalogs. The original pre-correction 947-execution install checks are historical evidence, distinct from this final-policy rerun.

## Reading overhead

`scripts/measure_read_paths.py BASELINE CANDIDATE` reports explicit read sets, UTF-8 bytes, whitespace words and documentation-link graphs. These are not model token counts, measured time or observed usability. Common command references are counted whole; an agent can read only relevant sections.

The initial candidate static read-inventory measurement showed lower selected documentation word counts, but these are pre-correction measurements and should not be presented as current execution costs.

## Separate evidence phases

1. **Frozen first pass:** ordinary tasks, continuation, routing and exact export were compared before corrections. One already-native standalone task demonstrated lower reported execution counts (23 versus 37) and selected-document bytes (40,255 versus 67,270). Counts were batching-sensitive, not timings or token measurements. Explicit portable work did not show the same reduction: reported calls increased from 20 to 28 despite a smaller selected-document footprint. Scope/finalization reminders and interrupted-run recovery limit unaided comparisons.
2. **Artwork outcomes:** 13 real generation calls were used across both arms. None of the four local/full-body animation trials finished with verified acceptable playback. The candidate's single cel passed native checks but its portable packaging initially failed. These small, unequal-scope samples do not demonstrate improved artistic reliability or statistical superiority. Routing matched 11/11 per arm; explicit exporter files were byte-identical with decoded pixel, timing, layer and tag checks. Desktop opening remains unverified.
3. **Bounded corrections:** synthetic regressions cover actual included-record/export consistency, explicit study supersession without deleting history or relaxing authority, and static single-cel bundle mapping. The preserved stale-export reproduction now rejects. A separate copy of the original single-cel inputs packages and relocates using the documented refinement stage, retaining one used and three remaining calls, with no invented timeline. This is packaging recovery, not a new artistic success or a rewritten first-pass result.
4. **Independent-review policy:** validated separately after correction, using existing artwork and zero new image-generation calls. All 21 static checks and 10 explicitly simulated control-flow probes passed. The simulations cover missing capabilities/evidence, disagreements, repair caps and review invalidation; they are not generated repair or playback trials.

Four fresh actual reviews produced distinct scoped results: the completed three-view set passed; a composed page-cross key needed revision for reversed hand roles, blocking dependent generation; a reused hop apex passed for still-pose scope; and a different final-animation reviewer left motion unverified because real playback was unavailable despite inspecting every static frame, transition and wrap. A metadata-only PNG change also triggered actual hash-bound re-review: decoded pixels were unchanged, so this was not an artistic repair. These observations demonstrate bounded policy use and honest evidence limits, not improved generated artwork, verified motion or broad reviewer reliability. Original frozen outcomes remain unchanged.


## Limits

Synthetic/install checks do not certify generated-art quality, cross-agent usability, native Windows/macOS/WSL execution, observed playback or an Aseprite desktop application-open check. Those evidence levels require separate reporting. Compact records are hash-checked local evidence, not authenticated or append-only history; previously uncaptured snapshots cannot be reconstructed. Existing full runs must continue their original snapshots/counters, while compact continuation uses the documented evidence-only bundle route.

No image-generation calls were made for these developer tests. Frozen matched artwork trials and correction retests are distinguished above; original results remain preserved. No license was added.
